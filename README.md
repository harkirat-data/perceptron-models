# Perceptron Models & Implementations

A progressive collection of Perceptron experiments demonstrating the geometric intuition, mathematical formulation, loss optimization, and architectural limitations of single-layer perceptrons.

---

## Models Included

| Folder | Topic | Description |
| :--- | :--- | :--- |
| **model1/** | Placement Prediction | 2D geometric intuition of Perceptron decision boundary on student placement data |
| **model2/** | Diabetes Classification | Perceptron applied on 8-feature medical records with PCA 2D projection |
| **model3/** | Custom Perceptron | Step-by-step from-scratch implementation of the Perceptron algorithm (weights update loop) |
| **model4/** | Loss & Convergence | Observing Perceptron loss convergence and weight dynamics across epochs |
| **5/** | Non-Linear Limitations | XOR problem and geometric proof of why single-layer perceptrons require MLPs |
